## 🎯 核心功能

### 1. 决策树系统

提供清晰的测试方法选择指南：
- 组件测试（Vue/React）
- API 测试（服务/接口）
- 端到端测试（完整流程）

### 2. 辅助脚本

#### run_tests_with_coverage.sh
```bash
# 基础使用
bash scripts/run_tests_with_coverage.sh

# 监听模式
bash scripts/run_tests_with_coverage.sh --watch

# UI 模式
bash scripts/run_tests_with_coverage.sh --ui

# 自定义阈值
bash scripts/run_tests_with_coverage.sh --threshold 85
```

#### setup_test_db.js
```bash
# 创建 SQLite 测试数据库
node scripts/setup_test_db.js

# 填充种子数据
node scripts/setup_test_db.js --seed

# 重置并重新初始化
node scripts/setup_test_db.js --reset --seed
```

### 3. 示例代码

#### 组件测试
- Vue 3 组件测试（使用 @vue/test-utils）
- React 组件测试（使用 @testing-library/react）
- 事件触发、属性断言、样式检查

#### API 测试
- 完整的 UserService 集成测试
- 数据库交互模拟
- 外部 API Mock 示例

#### E2E 测试
- 真实的电商购物车系统测试
- 6个完整场景（单商品购买、多商品购买、库存不足、修改购物车等）
- 业务流程完整验证

#### Mock 模式
涵盖 10 种 Mock 模式：
1. Mock 函数
2. Mock 模块
3. Mock 类
4. Mock 时间
5. 部分 Mock
6. Mock 环境变量
7. Mock 全局对象
8. Mock 实现
9. Spy 模式
10. 清理 Mock

### 4. 参考文档

- **vitest-api.md**: 完整的 Vitest API 参考（测试结构、断言、Mock API、配置等）
- **testing-library-cheatsheet.md**: Vue/React Testing Library 速查表

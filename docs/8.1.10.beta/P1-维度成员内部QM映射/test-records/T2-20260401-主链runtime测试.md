# T2 测试记录：主链 runtime 测试

- 日期：2026-04-01
- 阶段：阶段2
- 测试人：Codex

## 测试范围

- synthetic model 名直接进入 `QueryFacade.buildSqlOnly`
- simple 入口是否归一到 synthetic member-QM 后走主链
- synthetic member-QM 是否只暴露根维度子树字段
- 新主路径是否摆脱旧成员查询旁路作为核心依赖

## 测试数据

- 测试基类：`SyntheticMemberQueryModelRuntimeTest extends EcommerceTestSupport`
- 数据源：`sqlite` profile
- 目标模型：`FactSalesNestedDimQueryModel`
- 目标根维度：`product`

## 测试用例

### 1. synthetic model 直接生成 SQL

- 输入：
  - `queryModel = FactSalesNestedDimQueryModel#product`
  - `columns = [id, caption, productCategory$caption]`
- 预期：
  - SQL root 指向 `dim_product_nested`
  - SQL 包含 `dim_category_nested`
  - SQL 不回退到 `fact_sales_nested`

### 2. simple 入口归一

- 输入：
  - `queryModel = FactSalesNestedDimQueryModel`
  - `dimension = categoryGroup$groupType`
- 预期：
  - 能回溯到 `FactSalesNestedDimQueryModel#product`
  - 返回结果带 canonical `id/caption`

### 3. 字段边界校验

- 输入：
  - `queryModel = FactSalesNestedDimQueryModel#product`
  - `columns = [salesAmount]`
- 预期：
  - 构建 SQL 失败
  - 错误信息包含 `salesAmount`

### 4. loader 返回字段集合

- 输入：
  - `queryModelLoader.getJdbcQueryModel("FactSalesNestedDimQueryModel#product", null)`
- 预期：
  - 包含 `id`
  - 包含 `caption`
  - 包含 `productCategory$categoryGroup$groupType`
  - 不包含 `salesAmount`
  - 不包含 `store$caption`

## 实际结果

- `SyntheticMemberQueryModelRuntimeTest` 共 4 个用例全部通过
- `buildSqlOnly` 已落到维表 root
- simple 入口已通过 `QueryFacade` 查询返回 canonical `id/caption`
- synthetic member-QM 字段边界符合阶段2预期

## 结论

- 阶段2验收标准已满足：
  - simple 入口与 DSL 入口最终执行模型一致
  - synthetic member-QM 可被正常装载并进入主查询 pipeline
  - 可通过现有 SQL 生成能力输出 synthetic member-QM 的 SQL
  - 新主路径不再依赖旧维度成员旁路作为核心执行链

## 关键输入样例

- `FactSalesQueryModel + product$brand`

## 关键断言

- 普通维度可解析为唯一 synthetic model：`FactSalesQueryModel#product`
- 普通维度 schema 包含根维度 canonical 字段与 TM 全属性
- 多级嵌套字段可回溯到根维度 synthetic model：`FactSalesNestedDimQueryModel#product`
- 嵌套 schema 包含：
  - `productCategory$id/$caption/$categoryId/$categoryLevel`
  - `productCategory$categoryGroup$id/$caption/$groupId/$groupType`
- 父子维 schema 包含：
  - `id`
  - `caption`
  - `teamId`
  - `teamName`
  - `parentId`
  - `teamLevel`
  - `managerName`
  - `status`
  - `depth`
  - `hasChildren`
- `parentId` 使用 hierarchy 保留字段语义，sourceRef 为 `team$parentId`
- namespace 会被 trim，cacheKey 稳定为 `qa|FactTeamSalesQueryModel|team`

# 阶段3开发提示词

## 阶段目标

- 覆盖普通维度、嵌套子维度、父子维三类 synthetic member-QM 查询
- 确认嵌套子维度路径字段在 synthetic member-QM 下可查询、可过滤、可排序
- 确认父子维 hierarchy operator 在对应路径的 `$id` 字段上可工作

## 本阶段范围

- 在阶段 2 已完成的 synthetic member-QM 主链接入基础上，继续验证并补齐：
  - 根维度 canonical 字段查询结果
  - 一级、二级嵌套子维度路径字段查询
  - 嵌套子维度路径字段过滤与排序
  - 父子维 `childrenOf / descendantsOf / ancestorsOf / selfAndDescendantsOf / selfAndAncestorsOf`
- 本阶段以运行时可执行、测试可证明为准，不额外扩展新的 DSL 语法

## 设计约束

- 只考虑 `REFERENCE_QM`
- 不考虑 context permission
- 不做“当前业务数据里是否存在该成员”的裁剪
- 仍然只允许访问“根维度 + 内嵌子维度子树”字段
- `groupBy / orderBy / start / limit / columns / slice` 属于 QM 基础能力，不额外禁用
- 父子维 hierarchy operator 必须依赖现有主引擎能力，不能再开一条独立成员旁路

## 推荐实现方向

- 优先验证 synthetic member-QM 的运行时列是否保留了 hierarchy 所需的维度语义
- 如果 hierarchy operator 不能在 synthetic 字段上生效，优先修正 synthetic runtime column 的构造方式
- 复用现有嵌套维度 join graph，不为子维度单独新增 join 机制
- 测试优先直接走 `queryFacade.queryModelData(...)` 或 simple 入口真实查询结果，不只停留在 `buildSqlOnly(...)`

## 验收标准

- 可查询根维度属性
- 可查询一级、二级内嵌子维度的 `id/caption/属性`
- 可在子维度路径字段上执行过滤与排序
- 对父子维路径节点，`childrenOf / descendantsOf / ancestorsOf / selfAndDescendantsOf / selfAndAncestorsOf` 等操作可正确工作

  - synthetic member-QM 在子维度路径字段上的过滤与排序

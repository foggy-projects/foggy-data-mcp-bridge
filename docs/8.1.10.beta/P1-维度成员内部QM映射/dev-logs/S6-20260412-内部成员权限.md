## 关键设计决策

1. **TM 维度权限通过 BeanUtils.copyProperties 自动传递**：DbDimensionDef → DbDimensionSupport，无需手动 copy 代码
2. **QM 成员权限通过 QueryModelLoaderImpl step42 显式加载**：参照 loadAccesses() 模式
3. **InternalPatchStep @Order(-20)**：在 ExternalPatchStep(-10) 之前执行，确保内部 → 外部 → 请求的覆盖优先级
4. **QueryBuilderStep @Order(100)**：在所有 patch 合并完毕后执行，通过 extData 传递 effective permission
5. **FsscriptConversionService 自动处理嵌套对象转换**：无需手动解析 memberPermission 配置块

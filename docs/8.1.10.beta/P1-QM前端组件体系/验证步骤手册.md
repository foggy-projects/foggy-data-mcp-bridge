# QM 前端组件体系 — 验证步骤手册

## 环境准备

### 1. 启动 Docker 基础设施
```bash
cd foggy-dataset-demo/docker
docker compose up -d
```
确认以下服务运行中：
- MySQL: `localhost:13306` (foggy_test)
- MongoDB: `localhost:17017`

### 2. 打包并启动后端
```bash
# 打包
mvn package -pl foggy-mcp-launcher -am -DskipTests

# 启动（标准模式，含 data-viewer）
java -jar foggy-mcp-launcher/target/foggy-mcp-launcher-8.1.10.beta.jar \
  "--spring.data.mongodb.uri=mongodb://localhost:17017/foggy_viewer" \
  "--spring.datasource.url=jdbc:mysql://localhost:13306/foggy_test?useSSL=false&allowPublicKeyRetrieval=true" \
  --spring.datasource.username=foggy \
  --spring.datasource.password=foggy_test_123 \
  --server.port=7108
```

等待 `Started McpLauncherApplication` 日志输出。

### 步骤 6：直连查询 — 多条件筛选

**请求**
```bash
curl -s -X POST http://localhost:7108/data-viewer/api/query/direct/FactOrderQueryModel \
  -H "Content-Type: application/json" \
  -d '{
    "start": 0,
    "limit": 2,
    "slice": [
      {"field": "orderStatus", "op": "=", "value": "PAID"},
      {"field": "customer$id", "op": "in", "value": [1, 2, 3]}
    ],
    "orderBy": [{"field": "amount", "dir": "DESC"}]
  }' | python -m json.tool
```

**验证要点**

| 检查项 | 预期 |
|--------|------|
| `data.items[].orderStatus` | 全部为 `"PAID"` |
| `data.items[].customer$id` | 只有 1、2、3 |
| 按 amount 降序 | 第一条 amount >= 第二条 |
| `data.totalData` | 包含汇总信息 |

### 步骤 7：DataViewer 表格渲染

**步骤**
1. 先创建查询获取 queryId：
```bash
curl -s -X POST http://localhost:7108/data-viewer/api/query/create \
  -H "Content-Type: application/json" \
  -d '{
    "model": "FactOrderQueryModel",
    "title": "订单查询验证",
    "payload": {
      "columns": ["orderId", "orderStatus", "customer$caption", "orderTime", "amount", "payAmount"],
      "slice": [{"field": "orderStatus", "op": "=", "value": "PAID"}],
      "orderBy": [{"field": "orderTime", "order": "desc"}]
    }
  }'
```
记下返回的 `queryId`。

2. 浏览器打开 `http://localhost:7108/data-viewer/view/FactOrderQueryModel/{queryId}`

**验证要点**

| 检查项 | 预期 |
|--------|------|
| 页面标题 | "订单查询验证" |
| 显示列 | 订单ID、订单状态、客户(名称)、下单时间、订单总额、订单应付金额 |
| 订单状态列 | 筛选框显示 "PAID" |
| 客户列 | 显示 SelectFilter 下拉框 |
| 合计行 | 显示总条数和度量合计 |
| 分页 | 可翻页 |
| 列排序 | 点击列头可排序 |

## 已知限制

1. **GeneratedTableExample.vue**：需要通过 `npm run dev` 启动前端 dev 服务才能在浏览器中运行（App.vue 当前无路由到 example）
2. **QueryPanel**：需要前端 dev 服务 + querySchema 传入才能渲染，当前 DataViewer 页面走的是旧的 queryId 模式不涉及 QueryPanel
3. **远程维度过滤交互**：SelectFilter 升级后的远程搜索功能需要在前端 dev 模式下联调验证（当前打包到静态资源中的是构建后版本）

## 1. 可访问环境

### 后端服务

```bash
# 启动命令（需 Docker 基础设施运行中）
cd foggy-data-mcp-bridge

java -jar foggy-mcp-launcher/target/foggy-mcp-launcher-8.1.10.beta.jar \
  "--spring.data.mongodb.uri=mongodb://localhost:17017/foggy_viewer" \
  "--spring.datasource.url=jdbc:mysql://localhost:13306/foggy_test?useSSL=false&allowPublicKeyRetrieval=true" \
  --spring.datasource.username=foggy \
  --spring.datasource.password=foggy_test_123 \
  --server.port=7108
```

| 项目 | 值 |
|------|------|
| **服务地址** | `http://localhost:7108` |
| **API Base** | `http://localhost:7108/data-viewer/api/` |
| **DataViewer 页面** | `http://localhost:7108/data-viewer/view/{model}/{queryId}` |
| **JAR 路径** | `foggy-mcp-launcher/target/foggy-mcp-launcher-8.1.10.beta.jar` |

### Docker 前置（已运行）

| 服务 | 端口 | 账号 |
|------|------|------|
| MySQL | `localhost:13306` | `foggy / foggy_test_123`（库 `foggy_test`） |
| MongoDB | `localhost:17017` | 无认证 |
| PostgreSQL | `localhost:15432` | `foggy / foggy_test_123` |

### 前端 Dev 服务（可选）

```bash
cd addons/foggy-data-viewer/frontend
npm install
npm run dev
# 访问 http://localhost:5173
```

|--------|------|------|
| **`FactOrderQueryModel`** | 主验收模型 | 订单查询，40 字段，5 维度（含 memberLookup）、5 度量、2 字典 |

## 4. 业务页面 / 前端仓库路径

### API 端点验收

| 端点 | 方法 | 快速验证 |
|------|------|---------|
| 前端元数据 | GET | `curl http://localhost:7108/data-viewer/api/frontend-meta/FactOrderQueryModel` |
| 元数据下载 | GET | `curl -O http://localhost:7108/data-viewer/api/frontend-meta/download/FactOrderQueryModel` |
| 维度成员查询 | POST | `curl -X POST http://localhost:7108/data-viewer/api/members/query -H "Content-Type: application/json" -d '{"qmModel":"FactOrderQueryModel","fieldName":"customer$caption","limit":5}'` |
| 直连查询 | POST | `curl -X POST http://localhost:7108/data-viewer/api/query/direct/FactOrderQueryModel -H "Content-Type: application/json" -d '{"start":0,"limit":3}'` |
| 过滤选项 | GET | 需先通过 `/query/create` 创建 queryId |

### DataViewer 页面验收

```bash
# Step 1: 创建查询实例
curl -s -X POST http://localhost:7108/data-viewer/api/query/create \
  -H "Content-Type: application/json" \
  -d '{
    "model": "FactOrderQueryModel",
    "title": "验收测试",
    "payload": {
      "columns": ["orderId","orderStatus","customer$caption","orderTime","amount","payAmount"],
      "slice": [{"field":"orderStatus","op":"=","value":"PAID"}],
      "orderBy": [{"field":"orderTime","dir":"DESC"}]
    }
  }'

# Step 2: 用返回的 queryId 打开浏览器
# http://localhost:7108/data-viewer/view/FactOrderQueryModel/{queryId}
```

验收要点：
- ✅ 分页器可见（1-40 页，50条/页）
- ✅ 首行时间为最新（排序生效）
- ✅ 筛选器正常（PAID 已选中，客户下拉可点）
- ✅ 合计行显示
- ✅ 浏览器控制台零错误

### 代码生成器验收

```bash
cd addons/foggy-data-viewer/frontend

# 在线模式（需后端运行）
npm run gen -- --model FactOrderQueryModel --server http://localhost:7108 --output /tmp/gen-test

# 离线模式
npm run gen -- --file ../../docs/8.1.10.beta/P1-QM前端组件体系/examples/FactOrder.frontend-meta.json --output /tmp/gen-test
```

验收要点：
- ✅ 生成 6 个文件（types / table.schema / query.schema / api / Table.vue / index）
- ✅ memberLookup 自动关联
- ✅ query.schema 的 sourceField 归一到 `$id`

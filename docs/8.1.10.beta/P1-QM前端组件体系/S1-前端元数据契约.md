# S1 - 前端元数据契约 (frontend-meta v1)

## 基本信息
- 优先级：**P0**（所有生成器和组件的前置依赖）
- 状态：`已锁定`

## 目标
定义一套面向前端渲染和代码生成的标准 JSON 元数据格式，使前端不再直接依赖 V3 语义元数据的内部结构。

## 与 V3 的关系
- V3 是面向 LLM 的语义元数据（含 `prompt`、拼接 `meta`、`models` 嵌套映射）
- `frontend-meta v1` 是面向前端渲染的消费契约（数组结构、显式 title、能力声明）
- 后端实现上复用 `SemanticServiceV3Impl` 逻辑，输出时做结构转换

## 后端接口

### 运行时
```
GET /data-viewer/api/frontend-meta/{qmModel}
```
返回 `RX<FrontendMeta>`。

### 开发期下载
```
GET /data-viewer/api/frontend-meta/download/{qmModel}
```
返回 JSON 文件，供生成器离线使用或 CI 快照。

## JSON 顶层结构

```json
{
  "metaVersion": "v1",
  "model": "FactOrderQueryModel",
  "caption": "订单查询",
  "description": "订单事实表查询模型",
  "fields": [ /* FieldMeta[] */ ],
  "defaults": {
    "visibleColumns": ["orderDate$caption", "customer$caption", "orderId", "orderStatus", "amount"],
    "searchFields": ["orderId", "customer$caption"],
    "pageSize": 50,
    "orderBy": [{ "field": "orderTime", "order": "desc" }]
  },
  "capabilities": {
    "pageable": true,
    "sortable": true,
    "filterable": true,
    "aggregatable": true
  },
  "params": {
    "global": {},
    "custom": {}
  }
}
```

### 顶层字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `metaVersion` | `string` | 是 | 固定 `"v1"`，用于前端契约版本判断 |
| `model` | `string` | 是 | QM 模型名称 |
| `caption` | `string` | 是 | 模型显示名称 |
| `description` | `string` | 否 | 模型简要说明 |
| `fields` | `FieldMeta[]` | 是 | 字段数组（保证输出顺序） |
| `defaults` | `DefaultsMeta` | 否 | 默认显示列、搜索字段、分页、排序 |
| `capabilities` | `CapabilitiesMeta` | 否 | 模型级能力声明 |
| `params` | `ParamsMeta` | 否 | 全局参数和定制参数入口 |

## 字段结构 (FieldMeta)

```json
{
  "name": "customer$caption",
  "title": "客户(名称)",
  "type": "TEXT",
  "category": "dimension-caption",
  "filterType": "dimension",
  "filterable": true,
  "sortable": true,
  "measure": false,
  "aggregatable": false,
  "aggregation": null,
  "sourceColumn": null,
  "dictId": null,
  "dictMode": null,
  "calculated": false,
  "hierarchical": false,
  "hierarchyOps": null,
  "memberLookup": {
    "enabled": true,
    "selectionFieldName": "customer$id",
    "displayFieldName": "customer$caption",
    "searchable": true,
    "pageable": true,
    "defaultLimit": 20
  },
  "uiHints": {
    "visible": true,
    "required": false,
    "nullable": true,
    "format": null,
    "width": null
  }
}
```

### FieldMeta 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `string` | 字段唯一标识，对应 V3 `fieldName` |
| `title` | `string` | 显示名称，对应 V3 `name` |
| `type` | `string` | 数据类型：`TEXT` `STRING` `INTEGER` `BIGINT` `NUMBER` `MONEY` `DAY` `DATETIME` `BOOL` |
| `category` | `string` | 字段分类，见下方枚举 |
| `filterType` | `string` | 过滤器类型：`text` `number` `date` `datetime` `dict` `dimension` `bool` |
| `filterable` | `boolean` | 是否可筛选 |
| `sortable` | `boolean` | 是否可排序（新增，V3 无此字段） |
| `measure` | `boolean` | 是否度量字段 |
| `aggregatable` | `boolean` | 是否可聚合 |
| `aggregation` | `string?` | 默认聚合方式：`SUM` `AVG` `COUNT_DISTINCT` `MIN` `MAX` |
| `sourceColumn` | `string?` | 底层数据库列名（生成器 debug 用，组件不依赖） |
| `dictId` | `string?` | 字典标识 |
| `dictMode` | `string?` | 字典模式：`static`（开发期快照）/ `remote`（运行时远程加载） |
| `calculated` | `boolean` | 是否计算字段 |
| `hierarchical` | `boolean` | 是否层级维度 |
| `hierarchyOps` | `string[]?` | 可用层级操作（本版本 UI 只启用 `childrenOf`） |
| `memberLookup` | `MemberLookupMeta?` | 维度成员远程查询配置 |
| `uiHints` | `UiHintsMeta?` | 前端 UI 提示 |

### category 枚举

| 值 | 含义 | V3 对应 |
|----|------|---------|
| `dimension-id` | 维度 ID 字段 | `$id` 后缀字段 |
| `dimension-caption` | 维度显示字段 | `$caption` 后缀字段 |
| `dimension-property` | 维度属性 | `$propertyName` 后缀字段 |
| `attribute` | 普通属性 | 无 `$` 前缀的非度量字段 |
| `measure` | 度量 | `measure=true` 字段 |
| `calculated` | 计算字段 | `calculated=true` 字段 |

### MemberLookupMeta

```ts
interface MemberLookupMeta {
  enabled: boolean
  selectionFieldName: string   // DSL slice 使用的值字段
  displayFieldName: string     // 前端展示字段
  searchable?: boolean
  pageable?: boolean
  defaultLimit?: number
}
```

### UiHintsMeta

```ts
interface UiHintsMeta {
  visible?: boolean       // 是否默认可见
  required?: boolean      // 筛选时是否必填
  nullable?: boolean      // 是否允许空值
  format?: string         // 显示格式提示（如 'yyyy-MM-dd'）
  width?: number          // 建议列宽
}
```

## V3 → frontend-meta v1 映射规则

| V3 字段 | v1 字段 | 转换规则 |
|---------|---------|---------|
| `fieldName` | `name` | 直接映射 |
| `name` | `title` | 直接映射 |
| `type` | `type` | 直接映射 |
| `filterType` | `filterType` | 直接映射 |
| `filterable` | `filterable` | 直接映射 |
| `measure` | `measure` | 直接映射 |
| `aggregatable` | `aggregatable` | 直接映射 |
| `aggregation` | `aggregation` | 直接映射 |
| `dictId` | `dictId` | 直接映射 |
| `hierarchical` | `hierarchical` | 直接映射 |
| `hierarchyOps` | `hierarchyOps` | 直接映射 |
| `calculated` | `calculated` | 直接映射 |
| `sourceColumn` | `sourceColumn` | 直接映射 |
| — | `sortable` | 新增，默认 `true`（度量默认 `false`） |
| — | `category` | 根据字段命名和 meta 前缀推导 |
| — | `dictMode` | 默认 `static`；大字典或动态字典标记为 `remote` |
| — | `memberLookup` | `$caption` 字段：若同基名存在 `$id`，自动生成 |
| — | `uiHints` | 从已有字段推导默认值 |
| `meta` | — | 不透传 |
| `prompt` | — | 不透传 |
| `models.{}.description` | — | 不透传（可选放入 `description`） |
| `models.{}.usage` | — | 不透传 |
| `fields`（Object） | `fields`（Array） | 对象映射转数组，保证输出顺序 |
| `models`（Object） | `model` / `caption` / `description` | 提升到顶层 |

### memberLookup 自动推导规则

1. 字段名以 `$caption` 结尾，且同基名存在 `$id` 字段 → 自动生成 `memberLookup`
2. 字段名以 `$id` 结尾，且同基名存在 `$caption` → 不自动生成（前端过滤器默认挂在 `$caption` 上）
3. 无法推导成对 `$id/$caption` → 不开启 `memberLookup`
4. `hierarchical` 和 `hierarchyOps` 透传后端 metadata 已有值

## TypeScript 类型定义

```ts
// 建议添加到 foggy-data-viewer/frontend/src/types/index.ts

export interface FrontendMeta {
  metaVersion: string
  model: string
  caption: string
  description?: string
  fields: FieldMeta[]
  defaults?: DefaultsMeta
  capabilities?: CapabilitiesMeta
  params?: ParamsMeta
}

export interface FieldMeta {
  name: string
  title: string
  type: string
  category: FieldCategory
  filterType?: string
  filterable?: boolean
  sortable?: boolean
  measure?: boolean
  aggregatable?: boolean
  aggregation?: string
  sourceColumn?: string
  dictId?: string
  dictMode?: 'static' | 'remote'
  calculated?: boolean
  hierarchical?: boolean
  hierarchyOps?: string[]
  memberLookup?: MemberLookupMeta
  uiHints?: UiHintsMeta
}

export type FieldCategory =
  | 'dimension-id'
  | 'dimension-caption'
  | 'dimension-property'
  | 'attribute'
  | 'measure'
  | 'calculated'

export interface MemberLookupMeta {
  enabled: boolean
  selectionFieldName: string
  displayFieldName: string
  searchable?: boolean
  pageable?: boolean
  defaultLimit?: number
}

export interface UiHintsMeta {
  visible?: boolean
  required?: boolean
  nullable?: boolean
  format?: string
  width?: number
}

export interface DefaultsMeta {
  visibleColumns?: string[]
  searchFields?: string[]
  pageSize?: number
  orderBy?: Array<{ field: string; order: 'asc' | 'desc' }>
}

export interface CapabilitiesMeta {
  pageable?: boolean
  sortable?: boolean
  filterable?: boolean
  aggregatable?: boolean
}

export interface ParamsMeta {
  global?: Record<string, unknown>
  custom?: Record<string, unknown>
}
```

## 前端 API

```ts
// 建议添加到 foggy-data-viewer/frontend/src/api/viewer.ts

export async function fetchFrontendMeta(qmModel: string): Promise<FrontendMeta> {
  const res = await axios.get(`/data-viewer/api/frontend-meta/${qmModel}`)
  return res.data.data
}
```

## 验收标准
- [ ] `GET /data-viewer/api/frontend-meta/FactOrderQueryModel` 返回符合本规范的 JSON
- [ ] `fields` 为数组，顺序稳定
- [ ] 维度 `$caption` 字段自动包含 `memberLookup`，`selectionFieldName` 指向 `$id`
- [ ] 字典字段包含 `dictId` 和 `dictMode`
- [ ] 不包含 `prompt`、`meta`、`models` 嵌套映射
- [ ] 前端 `fetchFrontendMeta()` 可正常调用并获得类型安全的结果

# QM 前端组件体系 — 业务方接入指引

## 快速开始

### 方式 A：npm 包安装（推荐）

```bash
# 安装组件库（beta 版）
npm install foggy-data-viewer@beta

# 安装必须的 peer 依赖
npm install vue@^3.4 vxe-pc-ui@^4.11 vxe-table@^4.6 element-plus@^2.13 axios@^1.6 xe-utils@^3.5
```

> 若 `npm install foggy-data-viewer@beta` 提示版本过旧，说明新版尚未发布。
> 使用方式 B 直接从 Git 安装最新代码。

### 方式 B：Git 依赖安装

```bash
# 直接从 GitHub 安装最新 8.1.10-dev 分支
npm install github:foggy-projects/foggy-data-mcp-bridge#8.1.10-dev:addons/foggy-data-viewer/frontend

# 或本地开发时用 npm link
cd /path/to/foggy-data-mcp-bridge/addons/foggy-data-viewer/frontend
npm link
cd /path/to/your-project
npm link foggy-data-viewer
```

### 方式 C：直接复制源码

将 `addons/foggy-data-viewer/frontend/src/` 复制到你的项目中作为本地模块。

## 项目初始化

### 1. 注册全局依赖

在你的 `main.ts` 中：

```ts
import { createApp } from 'vue'
import VxeUI from 'vxe-pc-ui'
import 'vxe-pc-ui/lib/style.css'
import VxeTable from 'vxe-table'
import 'vxe-table/lib/style.css'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import zhCn from 'element-plus/dist/locale/zh-cn.mjs'
import App from './App.vue'

const app = createApp(App)

app.use(VxeUI)     // 必须在 VxeTable 之前
app.use(VxeTable)
app.use(ElementPlus, { locale: zhCn })

app.mount('#app')
```

> **关键**：`VxeUI` 必须在 `VxeTable` 之前注册，否则分页器和工具提示不可用。

### 2. 配置 API Base URL

如果后端不在同源，配置代理或 baseURL：

```ts
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/data-viewer/api': {
        target: 'http://localhost:7108',
        changeOrigin: true,
      },
    },
  },
})
```

## 使用方式

### 方式 1：代码生成器（推荐）

从后端元数据一键生成全套 TypeScript + Vue 代码：

```bash
# 确保后端运行中（http://localhost:7108）

# 生成单个模型
node node_modules/foggy-data-viewer/scripts/foggy-gen.mjs \
  --model FactOrderQueryModel \
  --server http://localhost:7108 \
  --output src/generated/qm/order

# 从离线 JSON 生成
node node_modules/foggy-data-viewer/scripts/foggy-gen.mjs \
  --file path/to/FactOrder.frontend-meta.json \
  --output src/generated/qm/order
```

生成产物：

```
src/generated/qm/order/
  FactOrder.types.ts           # 行类型
  FactOrder.table.schema.ts    # 表格列配置
  FactOrder.query.schema.ts    # 查询条件配置
  FactOrder.api.ts             # API 薄封装
  FactOrderTable.vue           # 可直接使用的表格组件
  index.ts                     # 统一导出
```

然后在业务代码中使用：

```vue
<!-- pages/order/OrderListPage.vue -->
<script setup>
import { FactOrderTable } from '@/generated/qm/order'
</script>

<template>
  <FactOrderTable show-query-panel>
    <template #toolbar>
      <button>导出</button>
    </template>
  </FactOrderTable>
</template>
```

### 方式 2：直接使用 DataTableWithSearch

不生成代码，直接使用标准组件 + API：

```vue
<script setup>
import {
  DataTableWithSearch,
  fetchFrontendMeta,
  fetchQueryDataDirect,
  fetchMemberOptions,
  buildTableColumns,
} from 'foggy-data-viewer'
import 'foggy-data-viewer/style.css'
import { ref, onMounted } from 'vue'

const QM_MODEL = 'FactOrderQueryModel'
const schema = ref(null)

onMounted(async () => {
  const meta = await fetchFrontendMeta(QM_MODEL)
  schema.value = {
    columns: buildTableColumns(
      meta.fields.map(f => ({
        name: f.name, title: f.title, type: f.type,
        filterType: f.filterType, filterable: f.filterable,
        measure: f.measure, dictId: f.dictId,
        memberLookup: f.memberLookup,
      })),
      { visibleColumns: meta.defaults?.visibleColumns }
    ),
    pageSize: meta.defaults?.pageSize || 50,
    showFilters: true,
    showPager: true,
  }
})

async function fetchData(params) {
  return fetchQueryDataDirect(QM_MODEL, {
    start: (params.page - 1) * params.pageSize,
    limit: params.pageSize,
    slice: params.slice,
    orderBy: params.orderBy,
  })
}
</script>

<template>
  <DataTableWithSearch
    v-if="schema"
    :schema="schema"
    :fetch-data="fetchData"
    :qm-model="QM_MODEL"
    :filter-member-loader="fetchMemberOptions"
  />
</template>
```

## 可用 API

| 函数 | 说明 |
|------|------|
| `fetchFrontendMeta(qmModel)` | 获取 frontend-meta v1 元数据 |
| `fetchQueryDataDirect(qmModel, request)` | 直连查询（无需 queryId） |
| `fetchMemberOptions(request)` | 维度成员远程搜索 |
| `fetchQmSchema(qmModel)` | 获取 V3 原始 schema |
| `fetchQueryData(model, queryId, request)` | queryId 模式查询 |
| `buildTableColumns(schema, config)` | 构建 EnhancedColumnSchema |
| `calculateColumnWidth(title, type)` | 自动计算列宽 |

## 可用组件

| 组件 | 说明 |
|------|------|
| `DataTableWithSearch` | 表格 + 搜索工具栏（推荐入口） |
| `QueryPanel` | 传统查询区（需传 querySchema） |
| `DataTable` | 纯表格组件 |
| `SearchToolbar` | 搜索工具栏 |
| `SelectFilter` | 下拉筛选（支持远程维度成员） |


```
  generated/qm/{model}/   # 生成器自动输出，禁止手改
  modules/{model}/         # 业务包装层（列覆盖、hooks、动作）
  pages/{model}/           # 页面层（路由、布局）
```

## 后端要求

业务方后端需运行 foggy-mcp-launcher（或集成 foggy-dataset-model + foggy-data-viewer addon），提供以下端点：

| 端点 | 用途 |
|------|------|
| `GET /data-viewer/api/frontend-meta/{qmModel}` | 元数据 |
| `POST /data-viewer/api/query/direct/{qmModel}` | 直连查询 |
| `POST /data-viewer/api/members/query` | 维度成员 |

## FAQ

**Q: vxe-pager 不显示？**
A: 确保 `main.ts` 中 `app.use(VxeUI)` 在 `app.use(VxeTable)` 之前。

**Q: 维度下拉不加载？**
A: 确保传了 `:qm-model` 和 `:filter-member-loader="fetchMemberOptions"` 给 DataTableWithSearch。

**Q: 生成器报 404？**
A: 后端服务需启动并有对应 QM 模型可用。可用 `--file` 模式从离线 JSON 生成。

# AI语音生成指南

## 推荐语音生成平台

**优势**: 音质优秀，支持多种语音风格
**费用**: 按使用量计费，相对经济

**推荐语音**:
- **度小美** - 标准女声
- **度小宇** - 标准男声

## 语音生成参数设置

### 基础参数
```json
{
  "语速": "中速偏快",
  "音调": "中等偏高",
  "音量": "标准",
  "发音人": "专业女声"
}
```

### 技术内容优化
- **语速**: 1.1-1.3倍正常语速
- **停顿**: 代码展示前后适当停顿
- **重音**: 关键技术术语加重语气

## 文本预处理指南

### 分段原则
按30秒为单位分段，每段约80-100字：

**示例分段**:
```
大家好！今天我们来解决一个让开发者头疼的问题——SQL注入风险。
当AI助手直接生成SQL查询时，数据安全如何保障？

这就是Foggy Data MCP Bridge的用武之地！
它通过DSL查询语法，彻底消除SQL注入风险。
```

### 技术术语处理
**英文术语**: 保持英文发音，但语速放慢
- MCP → "M-C-P"
- DSL → "D-S-L"
- SQL → "S-Q-L"

**中文术语**: 确保发音准确
- 语义层 → "yǔ yì céng"
- 注入 → "zhù rù"
- 查询 → "chá xún"

## 语音生成工作流

### 步骤1：文本分段
将脚本按时间节点分段，每段30秒内容

### 步骤2：参数设置
为每段设置合适的语速和语调

### 步骤3：生成测试
先生成小段测试，调整参数

### 步骤4：批量生成
按分段批量生成语音文件

### 步骤5：质量检查
检查发音准确性和自然度

## 常见问题解决

### 问题1：语音不自然
**解决方案**:
- 调整语速参数
- 增加适当停顿
- 使用更自然的语音模型

### 问题2：技术术语发音错误
**解决方案**:
- 手动标注拼音
- 使用发音字典
- 分段生成并校对

### 问题3：语音与画面不匹配
**解决方案**:
- 严格按照时间分段
- 预留剪辑缓冲时间
- 生成时考虑语速变化

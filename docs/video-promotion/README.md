# Foggy Data MCP Bridge 视频推广方案

## 项目概述

Foggy Data MCP Bridge 是一个 AI 原生语义层框架，基于 MCP 协议为 AI 助手提供安全、可控的数据查询能力。

- **视频2**：《AI数据分析师来了！5分钟集成Claude Desktop》

## 制作工具建议

### 视频制作
- **剪辑软件**：剪映、Premiere Pro
- **屏幕录制**：OBS Studio
- **动画制作**：After Effects（可选）

### AI语音生成
- **语音合成**：微软Azure语音、讯飞语音、百度语音
- **文本转语音**：支持中英文，选择自然流畅的语音包

### 字幕制作
- **自动字幕**：剪映自动识别
- **手动校对**：确保技术术语准确

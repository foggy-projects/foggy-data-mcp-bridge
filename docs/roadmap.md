## 8.2.x — 查询能力增强

> 目标：完善 SQL 分析能力闭环

### 里程碑规划

```
8.2.0  窗口函数 + CTE 支持
8.2.1  预聚合缓存 GA + explain
8.2.2  新增 MCP 统计 Tool
8.2.3  模型热加载
```

### 功能详情

#### 1. 窗口函数支持

| 函数类型 | 用途 | 优先级 |
|---|---|---|
| `LAG/LEAD` | YoY/MoM 同比环比计算 | P0 |
| `SUM() OVER` | Running Total 累计值 | P0 |
| `ROW_NUMBER/RANK` | 排名计算 | P1 |
| `NTILE` | 分位数分组 | P2 |

**方言兼容性注意**：
- SQLite 3.25+ 才支持窗口函数，需在 `FDialect` 声明能力
- 低版本 SQLite 优雅降级或报错提示

#### 2. CTE（公共表表达式）

- `WITH` 子句支持
- 递归 CTE（用于复杂层级查询）
- 与窗口函数配合使用场景

#### 3. 预聚合优化

- **explain 查询计划**：展示预聚合匹配过程
- **缓存命中率统计**：可观测性指标
- **增量刷新策略**：基于 watermark 的增量更新

#### 4. MCP Tool 扩展

| Tool | 说明 |
|---|---|---|
| `moving_average` | 移动平均 |
| `percentile` | 百分位数计算 |
| `top_n` | Top N 分析 |

> 注意：统计函数在 SQL 层实现，不引入算法引擎依赖

#### 5. 模型热加载

- TM/QM 文件变更监听
- 无需重启刷新模型定义
- 开发体验提升

### 暂不纳入

- **Vector Search**：业务场景不明确，推迟到 9.0 作为 addon
- **trend/anomaly 算法**：跨层依赖，建议独立 addon

## 8.3.x — Cloud Service

> 目标：纯 SQL 解析引擎，数据不动，模型云端管理

### 核心特性

#### Cloud Service 架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         Cloud Service                            │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐         │
│  │  TM/QM 文件  │    │  DSL 解析器  │    │  SQL 生成器  │         │
│  │  (用户上传)  │───▶│  (服务端)    │───▶│  (方言适配)  │         │
│  └─────────────┘    └─────────────┘    └─────────────┘         │
│                                                │                 │
│                                                ▼                 │
│                                         返回 SQL + 参数          │
└─────────────────────────────────────────────────────────────────┘
                                                 │
                                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                       用户环境（本地/私有云）                      │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐         │
│  │  业务数据库   │◀───│  SQL 执行器  │◀───│  Odoo/应用   │         │
│  │  (数据不动)  │    │  (客户端)    │    │  (发起请求)  │         │
│  └─────────────┘    └─────────────┘    └─────────────┘         │
└─────────────────────────────────────────────────────────────────┘
```

**核心原则**：
- **数据不动**：用户数据保留在本地/私有云
- **模型上传**：仅 TM/QM 模型文件上传到云端
- **SQL 返回**：服务端生成 SQL 返回给客户端执行
- **方言适配**：服务端根据用户数据库类型生成对应方言 SQL

**API 设计**：

```http
POST /api/v1/parse
Content-Type: application/json

{
  "namespace": "my-company",
  "model": "SalesOrderQueryModel",
  "dsl": {
    "slice": ["region", "product"],
    "measures": ["amount", "quantity"],
    "where": {...}
  },
  "dialect": "postgresql"
}
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "sql": "SELECT d1.name AS region, d2.name AS product, SUM(t1.amount) AS amount ...",
    "params": ["value1", "value2"],
    "metadata": {
      "columns": [...],
      "estimatedRows": null
    }
  }
}
```

**Odoo 集成优势**：
- 无需暴露 Odoo PostgreSQL 给外部服务
- 权限控制在 Odoo 侧完成
- 云端模型 + 本地数据，混合架构更安全

### 实现路径

**Phase 1：解析器服务化（8.3.0）**

- [ ] 抽象 `SqlGenerator` 接口（输入 DSL → 输出 SQL）
- [ ] 实现无状态解析服务
- [ ] TM/QM 模型存储（数据库/对象存储）
- [ ] 基础 API 端点

**Phase 2：客户端 SDK（8.3.1）**

- [ ] Java Client SDK
- [ ] Python Client SDK（Odoo 插件优先）
- [ ] SQL 执行器封装
- [ ] 连接池管理

**Phase 3：模型管理（8.3.2）**

- [ ] 模型版本管理
- [ ] 模型验证 API
- [ ] 命名空间隔离（用户级别）

## 9.0 — 企业级 & 生态建设

> 目标：SaaS 多租户、扩大用户基础、建立社区生态

### 企业级特性

#### 1. 多租户支持

| 隔离级别 | 说明 | 适用场景 |
|---|---|---|
| 逻辑隔离 | 共享 DB，Namespace 过滤 | SaaS 初期 |
| Schema 隔离 | 共享 DB 实例，独立 Schema | 中型租户 |
| 物理隔离 | 独立数据源 | 大客户 |

**第一阶段**：逻辑隔离（基于现有 Namespace 机制）

#### 2. 审计日志

- 查询审计：who queried what when
- 模型变更审计：TM/QM 版本历史
- 访问日志：API 调用追踪

#### 3. 频率限制 & 配额

- 基于 Redis 令牌桶
- 按 tenant/namespace 维度限流
- 配额管理 API

#### 4. 可观测性

- OpenTelemetry 集成
- 查询链路追踪
- 性能指标导出

### BI 工具集成

| 工具 | 方案 | 优先级 |
|---|---|---|
| Metabase | 自定义数据源插件 | P0 |
| Apache Superset | 数据源插件 | P0 |
| Grafana | 数据源插件 | P1 |
| Power BI | Custom Connector | P2 |

**建议提前到 8.3.x 末期**：快速扩大用户面

### Bridge SDK

- 标准化 ERP 对接框架
- 权限桥接抽象层
- 字段映射工具
- 具体 ERP（SAP、Salesforce）作为社区贡献

### DSL Prompt Toolkit

> **非自建 NL→DSL 模型**，而是提供 Prompt 生成工具

**设计思路**：

```
用户自然语言 → Prompt Toolkit → 结构化 Prompt → 用户自己的 LLM → DSL
```

**工具提供**：
- DSL Schema → Prompt 模板生成
- 字段描述自动提取
- 查询意图识别 Prompt
- Few-shot 示例生成器

### Marketplace

- 社区贡献 TM/QM 模型包
- 版本管理 + 依赖解析
- 评分 + 评论系统
- 与 Cloud Service 集成

## 风险与依赖

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| SQLite 窗口函数兼容性 | 部分用户无法使用 | 方言能力声明 + 降级提示 |
| Cloud Service 安全性 | 企业采纳门槛 | 数据不动设计 + 私有化部署选项 |
| 多租户隔离不彻底 | 数据泄露风险 | 分阶段推进，先逻辑隔离 |
| BI 插件维护成本 | 功能滞后 | 开源 + 社区贡献模式 |
